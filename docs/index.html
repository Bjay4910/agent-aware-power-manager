Agent Power Manager

A macOS menu bar app that keeps a MacBook awake with the lid closed while a coding agent is working, then releases the hold shortly after the agent finishes.

What the demo shows

  • The menu bar app and its menu.
  • A live hold and release: the icon changes between awake (⚡) and normal (🌙).
  • The 2-hour cap, from a real logged run (the logged run shown used a 180-second cap).
  • The 25% battery floor, shown through automated tests.

Limits

  • The battery floor is tested with fixtures, not real battery drain. Real battery drain below 25% is not yet tested.
  • Real-hardware results come from one MacBook Pro. Other Mac models are not yet tested.
